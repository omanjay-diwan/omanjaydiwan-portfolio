Featured Project

A practical analytics project combining a lending use case, SQL-based analysis and a Power BI dashboard.

Oracle SQL · Data Analysis · Power BI

Loan Origination & Credit Performance Analytics

Explore synthetic loan application data to understand application outcomes, decision turnaround time and monthly lending trends. The project demonstrates a data-to-dashboard workflow in a banking and financial services context.

Oracle Database SQL Views KPI Analysis Power BI Synthetic Data
Dashboard preview Static screenshot · Power BI report

Business questions

  • How are applications distributed across current statuses?
  • How does decision turnaround time vary by loan product?
  • How do application and decision volumes change month to month?

Technical approach

  • Organized synthetic lending data in Oracle tables.
  • Created SQL views for product turnaround, status distribution and monthly trends.
  • Designed a Power BI dashboard to communicate selected KPIs.

Data transparency: This project uses synthetic data created for demonstration. Figures are illustrative and do not represent real customers, a real lender or actual credit performance.
